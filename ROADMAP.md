# Roadmap

## Before a stable release

- Validate clean install, upgrade, rollback and removal on a disposable Linux host.
- Run acceptance tests against a non-production GLPI tenant and test WAHA session.
- Validate Browser Bridge packaging on supported Chromium and Firefox versions.
- Add a sanitized proactive-review screenshot to the portfolio gallery.
- Complete ownership review and select a distribution license.

## Product evolution

- Improve reconciliation tooling and retention controls for proactive operations.
- Review the experimental WAHA restriction patch against the pinned upstream release.
- Add SBOM and dependency scanning to the release evidence.
- Evolve to a hosted multiuser service with authentication, RBAC and tenant boundaries.
