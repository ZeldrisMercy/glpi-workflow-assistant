# Support

GLPI Workflow Assistant is a public beta maintained on a best effort basis.
There is no service-level agreement, guaranteed response time, production
support commitment or warranty.

## Where to ask

- Use GitHub Discussions for installation questions and workflow ideas.
- Use the bug template for reproducible defects that contain synthetic data.
- Use the feature template for scoped proposals.
- Follow `SECURITY.md` for vulnerabilities or suspected credential exposure.

Before opening a report, reproduce it on the current beta, remove customer and
environment data, and include the operating system, application version,
commands run, expected result and sanitized evidence.

The maintainer may close requests that cannot be reproduced, expose private
data, depend on unsupported environments or ask for operational access to a
real GLPI/WAHA instance.
