# Code of Conduct

## Our standard

Be respectful, technically honest and constructive. Welcome questions from
people with different levels of experience. Critique code and decisions,
never a person's identity or ability.

Unacceptable behavior includes harassment, discrimination, threats, sexualized
attention, publishing another person's private information, deliberate
misrepresentation of security findings and sustained disruption of project
spaces.

## Scope

This standard applies to Issues, Discussions, pull requests, reviews and other
spaces where someone is representing this project.

## Reporting and enforcement

For ordinary conduct concerns, contact the maintainer privately through the
GitHub profile linked from the repository owner. Security vulnerabilities must
follow `SECURITY.md`, not a public Issue. The maintainer may edit or remove
content, reject contributions or temporarily/permanently restrict participation
when behavior threatens a safe and productive project space.

Enforcement decisions will consider context, impact and whether harmful
behavior is corrected. This single-maintainer beta does not promise a formal
appeal body or response time.
