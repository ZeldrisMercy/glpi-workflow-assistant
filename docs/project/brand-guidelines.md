# Visual identity

GLPI Workflow Assistant uses a restrained open source technical system: dark
graphite surfaces, electric blue and violet for flow, and green only for a
state that has been verified or approved.

| Token | Value | Use |
|---|---|---|
| Graphite | `#090d16` | Primary background |
| Surface | `#111827` | Cards and process nodes |
| Electric blue | `#38bdf8` | Input and transport |
| Indigo | `#6366f1` | Planning and Dry Run |
| Violet | `#a855f7` | Human review checkpoint |
| Verified green | `#22c55e` | Confirmed/approved states only |
| Primary text | `#f8fafc` | Titles and high-emphasis copy |
| Secondary text | `#94a3b8` | Explanations and metadata |

Use monospaced type for technical labels and a neutral sans serif for prose.
Prefer pipelines, trust boundaries, receipts and graph nodes over decorative
“hacker” imagery. Do not combine this identity with an employer, customer or
third-party product logo.

`mark.svg` is the project mark; `hero.svg` is the README header;
`architecture-overview.svg` is the reusable technical visual; and
`social-preview.svg`/`.png` are the 1280×640 GitHub/LinkedIn preview pair.
