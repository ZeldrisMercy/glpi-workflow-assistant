# Evidence Model

## Contexto
Imagem usada apenas para compreender o caso.

## Evidência
Imagem explicitamente marcada para vínculo com tarefa/ticket (`E01`, `E02`...).

## Regra
Contexto não vira evidência automaticamente.

## Requisitos
- preview;
- ordem;
- associação explícita;
- automação apenas quando inequívoca;
- erro visível em referência não resolvida;
- sem “adivinhar” attachment.
